# Folder: public/music

Letakkan file audio (.mp3/.ogg) di folder ini. Ubah `playlist.json` untuk cocokkan nama file dan judul.

Contoh file yang bisa Anda isi:
- track1.mp3
- track2.mp3
- track3.mp3
- track4.mp3
- track5.mp3

Player akan mencoba memutar otomatis; jika browser memblokir autoplay, tombol Play akan muncul di pojok untuk mengaktifkan audio.
